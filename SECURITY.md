# Security Policy

## Supported Versions

Until the first stable mainnet release, security fixes target the latest `main` branch. Testnet deployments and unreleased commits are for development and evaluation.

## Reporting a Vulnerability

Please report suspected vulnerabilities through GitHub's private vulnerability reporting for this repository (the repository's **Security** tab → **Report a vulnerability**). Do not open a public issue for an unpatched vulnerability.

Include the affected component and commit, the impact, and steps to reproduce. Avoid including private keys, credentials, personal data, or private endpoint details in a report. Maintainers will coordinate follow-up and disclosure through the private report.

The policy covers NEAR contracts, the Console, SDK, evaluators, and Cloudflare Workers.
